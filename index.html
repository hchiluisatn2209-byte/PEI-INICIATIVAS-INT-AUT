📋 JSON copiado al portapapeles

Sigue estos pasos para importar los datos en Google Sheets:

  1. Abre el Apps Script de tu Google Sheet
  2. Busca la función importarDesdeJSON()
  3. Entre los corchetes [ ] de jsonData, pega el JSON (Ctrl+V)
  4. Selecciona importarDesdeJSON en el desplegable de funciones
  5. Clic en ▶ Ejecutar
